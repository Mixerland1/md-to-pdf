# 0.4.0 beta 14 — desktop workflow and Windows installation

Center welcome card at 50%/50%. Add slow moving pulses along actual SVG tracks, modeled on Phantom home hero timing, paused when hidden. Ctrl+wheel zoom preserves selection and cursor-relative page position, with horizontal scrolling. Toolbar uses folder, clipboard, save, PDF, undo/redo and update icons with tooltips; opening from editor returns to welcome with a back action. MD/TXT keep native workspace; DOCX, PDF, XLSX, XLS and CSV copy text into editable import view. PDF requires a text layer; Excel uses cached cell values, Word retains headings/lists/tables but not images or exact styling. Imported sources are not overwritten. Legacy .doc not supported. No OCR.

Windows setup installs under Program Files, provides desktop and Start menu shortcuts and uninstall registration. Portable ZIP remains for existing users and auto-updates. To switch from portable, download Setup.exe once; it is not automatic migration. Installed builds select verified Setup.exe updates and use normal Windows elevation and installer wizard. Installer is not code-signed. Setup and portable archives are subject to automated build and smoke checks. Manual desktop/installation acceptance pending.
