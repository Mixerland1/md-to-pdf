# 0.4.0 beta 2 — single-document workspace

Open or drop one document directly into the main editor. Choose a preset, select text on the actual rendered PDF page, apply a style, and export the exact preview bytes. No desktop batch queue, path fields or output explanations. CLI batch is retained. Preset switching replays compatible local edits; ambiguous or incompatible text selections are not silently changed. Header fields are available from the page context menu. Actual PDFs are rasterized locally with PDFium; page selection is mapped via layout anchors and exact text matches. Some complex text runs, nested structures or blocks crossing pages may not map; these remain visible and exportable. Manual GUI and updater acceptance pending. Windows update mechanism from beta 1 retained; Mac downloads only.
