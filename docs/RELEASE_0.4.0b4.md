# 0.4.0 beta 4 — selection and formatting

Single click selects the mapped semantic block. Drag selects text and displays draggable handles. Highlighting merges adjacent glyphs by line. Toolbar reports selected paragraph/inline role, font and actual PDF point size; mixed selections display separate mixed indicators. Selection is restored after formatting when text mapping permits. Font and size overrides apply to selected characters. The one-shot format brush copies uniform role, font and size. Save stores a local .mdtopdf sidecar with source hash, preset and validated style operations; reopening the source restores saved edits. Export remains the exact rendered PDF. No source changes. Complex unmapped text, nested list/table paragraph changes and manual desktop acceptance remain limitations. Windows updater retained; Mac direct download only.
Follow-up: reflects installed family names where PDF font names match; reports quote role for nested quote paragraphs; adds GUI acceptance smoke for click selection, style reflection, preservation of selection, and local save. Separate version prevents concurrent beta 3 builds from claiming the same final release.
