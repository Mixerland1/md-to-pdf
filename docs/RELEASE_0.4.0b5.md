# 0.4.0 beta 5 — visual refresh and clipboard import

The selected startup artwork is included as a compressed local WebP, and the editor toolbar uses a decorative strip cropped from the approved header reference. Real controls remain native Tk widgets, with a coordinated light blue palette; OS title bar remains native. No additional permanent update button.

Open, drop or paste plain text/Markdown from the clipboard (Ctrl+V, Command+V on macOS, or the welcome button). Pasted content opens immediately in the same editor. No source file is required in advance: a private temporary Markdown file backs the existing renderer. Rich clipboard formatting and copied images are not imported. Export asks for a PDF path the first time; repeated exports replace it. Save asks for a new Markdown filename and saves its .mdtopdf sidecar, protecting existing source files. File-based documents retain previous export/save rules. Clipboard data stays local; external resource access is still restricted. The actual final document remains generated by the same PDF engine, without application artwork.

Windows automatic update checks at startup remain unchanged, macOS offers direct download. Manual visual and end-to-end update acceptance pending.
