# Руководство пользователя

Granulex Example 1.2.3
Последнее обновление: ноябрь 2026

Этот контрольный документ содержит синтетический текст для проверки фирменного оформления. **Полужирный текст**, *курсив* и [внешняя ссылка](https://example.com).

## 1. Подготовка

- Проверьте конфигурацию.
- Выберите параметры:
    - основной режим;
    - дополнительные настройки.

1. Откройте приложение.
2. Выберите документ.
3. Сохраните результат.

### 1.1. Параметры

| Параметр | Значение | Описание |
|---|---|---|
| Режим | Стандартный | Проверка параметров |
| Код | 001 | Контрольная запись |
| Статус | Готово | Результат обработки |

> Важно. Перед применением настроек проверьте исходный документ.

Выполните команду `example --check`.

```bash
example --check
example --output result.pdf
```

#### Результат

Документ готов к проверке.
